# Atomic Red Team Setup

## Overview

Atomic Red Team was deployed on the Windows 11 endpoint to simulate real-world adversary techniques based on the MITRE ATT&CK framework. These controlled simulations were used to validate the effectiveness of Wazuh detections and confirm that endpoint telemetry generated by Sysmon was successfully ingested and analysed.

## Objectives

- Deploy Atomic Red Team on the Windows endpoint.
- Prepare the environment for adversary emulation.
- Execute ATT&CK techniques safely.
- Validate Wazuh detections generated during testing.

## Validation

The installation was considered successful after:

- Atomic Red Team loaded successfully.
- Test techniques were available for execution.
- The Wazuh agent remained connected.
- Sysmon continued collecting endpoint telemetry.
- Wazuh successfully received generated events.

## Outcome

The environment was successfully prepared for detection engineering activities using Atomic Red Team. The platform is now capable of executing controlled attack simulations to validate existing detections, identify monitoring gaps, and support future detection rule development.
